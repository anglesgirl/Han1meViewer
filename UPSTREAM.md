# Upstream sync

The canonical source repository for syncing this project is [`misaka10032w/Han1meViewer`](https://github.com/misaka10032w/Han1meViewer), branch `main`. The canonical Git remote name is `upstream`.

```sh
git remote set-url upstream https://github.com/misaka10032w/Han1meViewer.git
git fetch upstream main
```

Keep `origin` pointed at `anglesgirl/Han1meViewer` for this project. Review upstream changes before integrating them. The GitHub fork-parent/source metadata is separate from the fetch remote and is not changed by these instructions.
